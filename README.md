# 🧪 Peptide Calculator

A modern, interactive **Peptide Dosage Calculator** built with **HTML, CSS, and JavaScript**.
This tool helps researchers quickly calculate peptide dosages with precision, visualize syringe units, and review detailed results like concentration, volume to draw, and doses per vial.

⚠️ **Disclaimer**: This calculator is provided for **educational and informational purposes only**. It is **not medical advice**. Always consult a licensed healthcare professional before making any medical decisions.

---

## 🚀 Features

* **Peptide Vial Size Selection** – Predefined options (5mg, 10mg, 15mg, etc.) + custom input.
* **Bacteriostatic Water Volume** – Choose from quick options (1–5 mL) or enter custom.
* **Desired Dose** – Select common doses (100mcg, 250mcg, 1mg, etc.) or input custom with unit toggle (mcg/mg).
* **Instant Results**:

  * ✅ Concentration (mg/mL)
  * ✅ Volume to draw (mL)
  * ✅ Syringe units
  * ✅ Doses per vial
* **Syringe Visualization** – Animated fill bar with tick marks (0–100 units).
* **Mobile Responsive** – Optimized for desktop, tablet, and mobile devices.
* **Error Handling** – Prompts user if inputs are missing or invalid.

## 🔧 Installation & Usage

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/peptide-calculator.git
   ```
2. Open `index.html` in your browser.
3. Start calculating peptide dosages instantly.
